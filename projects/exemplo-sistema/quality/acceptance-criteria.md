# Critérios de Aceite: Exemplo Sistema

> Modelo demonstrativo. Defina critérios específicos para cada requisito.

## Funcionalidade
- [ ] Os requisitos funcionais aplicáveis foram atendidos.
- [ ] Os fluxos principais e alternativos foram testados.
- [ ] Erros e entradas inválidas são tratados adequadamente.

## Qualidade técnica
- [ ] Testes relevantes foram executados e os resultados registrados.
- [ ] A alteração segue a arquitetura e os padrões aprovados.
- [ ] A documentação necessária foi atualizada.

## Segurança e privacidade
- [ ] Nenhum segredo foi incluído nos arquivos ou logs.
- [ ] Validações e permissões foram verificadas.
- [ ] Os dados usados em testes são apropriados e minimizados.

## Revisão e entrega
- [ ] O diff foi revisado.
- [ ] Achados bloqueadores foram resolvidos ou encaminhados.
- [ ] Limitações e riscos residuais foram comunicados.
- [ ] Aprovações necessárias foram obtidas.
